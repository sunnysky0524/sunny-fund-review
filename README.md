# Sunny Fund Review · 200 題文字版（含校對工具）

- `index.html`：章節練習、隨機測驗、錯題本、收藏、成績匯出。
- `audit.html`：**原始圖片與文字並排**，可修正題目、選項、答案、備註並標記人工核對。修正先存於瀏覽器，按「匯出修訂題庫 JSON」產出可取代 `questions.json` 的資料。
- `questions.json`：200 題文字題庫；部分仍是 OCR 待校對，**不可視為全部校對完成**。
- `assets/`：200 張原始圖片。

## 啟動

使用 GitHub Pages，或在資料夾內執行 `python -m http.server 8000`，再開啟 `http://localhost:8000`。請勿直接雙擊 HTML，因為瀏覽器可能阻止讀取 JSON。
