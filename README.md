## 目前版本

- 已上傳 78 題完整文字題目、A～D 選項與教材答案。
- 原始整理共 200 題；**剩餘 122 題及原圖尚未上傳 GitHub**，此版本不是完整 200 題。
- 支援章節練習、隨機 20 題、即時判分、錯題本、收藏、瀏覽題庫。
- 學習紀錄使用瀏覽器 localStorage，不跨裝置同步。

## GitHub Pages 發布

在儲存庫 Settings → Pages → Build and deployment 選擇 **Deploy from a branch**、分支 **main**、資料夾 **/(root)**，然後儲存。網站預期網址：
https://sunnysky0524.github.io/sunny-fund-review/

題庫資料位於 `questions.json`，網站入口為 `index.html`。
